# v1.5.0 — 2026-11-25

This release adds a large set of offline Vedic calculation features, deterministic
interpretation helpers, report visualizations, standalone SVG chart export, local
chart API, dual licensing, and packaged agent skills. Every feature runs locally;
no paid services or subscriptions are required.

Tag: `v1.5.0`
Versions synced: `SKILL.md` 1.5.0, `pyproject.toml` 1.5.0, all packaged skills 1.5.0.
Tests: 82 passing, 6 skipped (optional external datasets).

## Highlights

- **Full instant Panchanga** — all five limbs (vara, tithi, nakshatra, yoga,
  karana) in chart JSON and the HTML atlas, explicitly marked as not
  sunrise-anchored.
- **Offline Vedic calendar** — sunrise-based monthly Panchanga JSON for a
  supplied location/timezone.
- **Festival and vrata dates** — optional offline PyJHora adapter for regional
  festivals and named vratas, plus a source-backed 58-system dasha catalog.
- **252-rule Jyotisha indicator library** — deterministic interpretive templates
  (108 graha-in-bhava + 144 bhava-lord placements) producing up to 21
  chart-specific evidence cards.
- **Ten Tamil Dasa Porutham checks** — runnable alongside the existing
  Ashtakoota 36, with `--method porutham10` or `--method both`.
- **Offline report visuals** — percentage bars, timelines, exact-value tables,
  and step diagrams rendered to HTML (printable to A4 PDF).
- **Standalone SVG chart export** — seven self-contained `.svg` files per chart.
- **Local chart API** — optional localhost-only JSON API; request bodies are not
  written to access logs.
- **Dual licensing** — AGPL-3.0-or-later or a commercial license for proprietary use.
- **Packaged agent skills** — SKILL.md variants for Hermes, Claude Code,
  OpenCode, and OpenAI, plus two new report skills.

## Vedic calculation and interpretation

- Instant-based Panchanga limbs added to `chart.json` and `charts.html`, with an
  explicit warning that they are not sunrise-anchored (`7476ab8`).
- Sunrise Vedic calendar CLI: `hermes-vedic-calendar` generates offline monthly
  JSON for a supplied location/timezone (`be57a3b`).
- Optional offline PyJHora adapter for festivals and vrata dates, a 58-system
  dasha selector catalog, and 22 upstream language identifiers with six-language
  festival translation coverage (`e1d3ee0`).
- `scripts/vedic_predictions.py`: 252 deterministic templates (9 grahas × 12
  bhavas = 108; 12 lords × 12 placements = 144). A chart yields up to 21
  evidence-linked cards. Sources: BPHS ch. 11–24. No health, lifespan, spouse
  death, or investment predictions (`608e49a`).
- Ten Porutham checks added to `guna_milan.py`: Dina, Gana, Mahendra, Stree
  Deergha, Yoni, Rasi, Rasyadhipathi, Vasya, Rajju, Vedha (`608e49a`).
- New reference docs: `references/full-vedic.md`,
  `references/vedic-insights-and-porutham.md`, and expanded `panchanga.md`.

## Reports and visuals

- `scripts/report_visuals.py`: offline renderer for `percentage-bars`, `timeline`,
  `table`, and `steps` sections. Output HTML opens offline and prints to PDF via
  the browser (`64488af`).
- Chart atlas and Fortune HTML now include a D1 house distribution and a
  Vimshottari dasha timeline; the Fortune PDF includes the house distribution.
- New agent skills: `skills/report-charts/SKILL.md` and
  `skills/report-diagrams/SKILL.md` for bespoke diagrams.
- New CLI: `hermes-report-visuals --spec assets/report-visuals.example.json
  --out reports/visuals.html`.
- Standalone SVG export: `hermes-astrology --svg` or
  `hermes-astrology-svg --chart chart.json --out svg/`. Writes `western-wheel.svg`
  plus north/south Indian D1, D9, and D10 diagrams.

## API, validation, and engineering

- `hermes-astrology-api`: optional localhost-only JSON API; bodies are not
  logged (`c32165e`).
- External-vector fixture validation with required source/version, retrieval
  date, settings, expected values, tolerance, and redistribution notes
  (`c32165e`). Documented that fixture tooling is not itself independent
  accuracy evidence (`2c1557a`).
- `uv.lock` for deterministic dependency installs; `pyrightconfig.json` for
  static type checking of `scripts/`.
- CI runs on Ubuntu and Windows with Python 3.11–3.13.

## Known limitations

- Regional festival and vrata lookups require the optional PyJHora adapter and
  remain subject to source and translation limits.
- General transit-event searches, rectification, and divisional charts beyond
  D9/D10 remain outside the calculator's scope.
- Jyotisha indicators are evidence-linked themes, not guaranteed events.
- Astrology is a traditional symbolic practice, not an established science.
  No medical, financial, legal, or other professional advice is provided.
- External Jagannatha Hora / Drik Panchang known-answer vectors remain pending;
  practitioner review is documented in `docs/conventions-review.md`.
