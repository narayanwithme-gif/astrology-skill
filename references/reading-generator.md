# Deterministic reading generator

`scripts/reading_gen.py` turns `chart.json` into a reproducible `reading.md`
without any LLM in the loop. The same input always produces byte-identical
output. The LLM edits prose only when the user explicitly requests a narrative
rewrite; the canonical reading generated by this script is the source of truth.

## Contract
- Input: `--chart chart.json --request request.json --out reading.md`
- Output covers §§1–11 of `references/report-template.md` with tables and
  house paragraphs derived directly from chart.json values.
- No claim may use a value not present in chart.json. Missing techniques
  (shadbala, ashtakavarga, etc.) are listed as not assessed.
- Templates are versioned; change the format only by bumping the template
  version and updating the golden test.

## Status table mapping
- computed: D1/D9/D10, aspects, graha drishti, tithi, MD/AD, transit snapshot
- not assessed: shadbala, ashtakavarga, KP, Jaimini, full panchanga, exact-event search
