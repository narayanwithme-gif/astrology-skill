# Ashtakavarga

Request `"vedic": ["ashtakavarga"]` under `advanced`. The calculator uses the placements in the main sidereal Rashi chart and counts from each contributor's sign as position one.

The seven recipient rows follow Varahamihira's [Brihat Jataka, chapter 9, verses 1–7](https://chestofbooks.com/new-age/astrology/Brihat-Jataka/Chapter-IX-On-Ashtakavargas.html), in N. Chidambaram Aiyar's translation. Each row uses the seven classical grahas and Lagna as contributors. Each contributor can give one point to a sign. Bhinna rows are ordered Aries to Pisces, and Sarva adds the seven rows by sign. The total before reductions is 337. The report includes the same Sarva totals in whole-sign house order.

The worked Mars example from the text is covered in the tests. The method follows this textual table before trinal or sign-ownership reductions.
