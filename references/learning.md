# Tutoring and memory

Teach one short lesson: learning objective, separate Western/Jyotisha explanation, overlap/differences, one worked example and three understanding questions. Use supplied charts for personal examples; otherwise explicitly fictional examples. Answer exercises directly when requested and explain corrections.

Suggested progression: (1) foundations; (2) calculation/zodiacs/ayanamsha/houses/time; (3) planets/grahas and sign qualities; (4) houses/lords; (5) aspects/drishti; (6) dignity/condition/yoga caution; (7) transits/dashas; (8) synthesis/source literacy; (9) chart construction practice; (10+) topic and advanced lessons chosen by the learner. This is a curriculum, not a claim there is a fixed total number of lessons in astrology.

Resume the learner's saved progress when available. Ask before assuming which lessons they have completed. Save date, lesson/topic, settings, demonstrated understanding vs material merely presented, corrections, exercises pending, exact output paths and next step. Do not mark a concept mastered because the AI supplied its answer.

Use Hermes's established memory tool or a user-chosen local study notebook. If no memory tool exists, save study-note.md next to the report and say where. Do not claim permanent model retraining or silently overwrite a different learner's profile. Saved notes support later retrieval; they do not ensure every future session will automatically load them.
