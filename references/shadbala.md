# Shadbala estimates

Request `"vedic": ["shadbala"]` under `advanced`. The report covers the seven classical grahas and describes the approximations alongside the numbers.

| Component | Calculation |
| --- | --- |
| Sthana | Sign dignity points plus Uccha, which scales distance from the exact debilitation point |
| Dig | Angular distance from the strongest direction defined by the Ascendant or Midheaven axis |
| Kala | Local clock hour using 06:00–18:00 as the day interval |
| Cheshta | A two-level estimate based on direction of motion |
| Naisargika | Fixed natural-strength values in seven equal steps up to 60 |
| Drik | Weights for full sign-based aspects received |

`uccha_bala` is shown separately for inspection and is already included in `sthana_bala`. Interpret the total as a simplified component estimate. Full classical Sthana, Kala, Cheshta and Drik calculations need additional rules and reference vectors.
